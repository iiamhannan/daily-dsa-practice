# Daily DSA Practice

A running log of Data Structures & Algorithms problems, solved one (or more) per day
to build consistency and sharpen problem-solving skills.

## Structure

```
daily-dsa-practice/
├── python/
│   ├── day01_two_sum.py
│   ├── day02_reverse_string.py
│   ├── day03_valid_palindrome.py
│   ├── day04_maximum_subarray.py
│   ├── day05_contains_duplicate.py
│   ├── day06_valid_anagram.py
│   ├── day07_binary_search.py
│   ├── day08_fibonacci.py
│   └── ...
└── README.md   (progress log below)
```

Each file is self-contained: the problem statement is in the docstring at the top,
the solution follows, and a few test cases run at the bottom via `if __name__ == "__main__":`
so you can just run `python day01_two_sum.py` to see it work.

## How I use this repo

- Solve one problem a day (small ones count — consistency > difficulty).
- Name files `dayNN_problem_name.py` in order.
- Add a one-line entry to the **Progress Log** below each time.
- Topics rotate: arrays, strings, hashing, two pointers, recursion, sorting,
  linked lists, stacks/queues, trees, dynamic programming.
